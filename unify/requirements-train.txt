# PyTorch. The line below installs the CPU build, which is enough to run
# everything here. For your RTX laptop install the CUDA build instead:
#   pip install torch --index-url https://download.pytorch.org/whl/cu124
# then verify:  python -c "import torch; print(torch.cuda.is_available())"  -> True
# If it prints False you installed the CPU wheel.
# NB: plain `pip install torch` on Windows resolves to the CPU-only wheel
# (torch-2.13.0+cpu) and silently trains on the CPU — 80 s/epoch on C-MAPSS
# instead of seconds, with the GPU idle. Check for the "+cu" suffix, not just
# that torch imports:
#   python -c "import torch; print(torch.__version__)"   -> must contain +cu
# Install the CUDA build explicitly, matching the version so the ONNX export
# path does not shift underneath you:
#   pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cu130
